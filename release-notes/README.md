# Release notes

One file per version, `<major>.<minor>.<patch>.md`, in German, for the people who use
Slipstream: a few bullets (`- `), each a sentence or two, what changed for them and what to do,
if anything. A line indented by two spaces continues the bullet above it; other lines are left
out. `**fett**` stays bold. Sparkle's update dialog, the GitHub release and the app's "Neu in …"
and "Über Slipstream" show them (docs/release.md, "Release notes"). A tag without its file does not
build.
