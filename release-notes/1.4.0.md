# Slipstream 1.4.0

- **Ein Slipstream für alle Rechner:** Der Mac und die Linux-Server laufen jetzt mit demselben
  Slipstream in derselben Version. Die Encoder-Seite im Funkhaus zeigt „Slipstream 1.4.0“ für
  jeden Rechner.
- **Auf dem neuesten Stand:** Dieser Mac bekommt alles, was der Server schon kann: Peaks,
  Filmstreifen und Lautheit für die Zeitleiste und die verbesserten Filmstreifen von
  iPhone-Videos. Sie müssen nichts tun.
